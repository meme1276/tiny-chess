A chess engine in 4 KB of Python: 0x88 mailbox board, negamax alpha-beta with iterative deepening under a fixed node budget, quiescence search (captures, promotions, full evasions in check, delta pruning), transposition table, capture and killer-move ordering, check extensions, formula piece-square tables. Deterministic: no clock, no randomness.

## Run it

```sh
MAKEFUN_ENV_URL=<env-url> python3 main.py
```
